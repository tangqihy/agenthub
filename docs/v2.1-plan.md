# AgentHub V2.1 — Agent Evolution

> **核心假设**：有价值的能力，能否从一次对话中沉淀成可复用、可演化的 Agent？

---

## 数据模型变更

### agents 表新增字段

| 字段 | 类型 | 说明 |
|------|------|------|
| usage_count | INTEGER DEFAULT 0 | 被使用的次数 |
| last_used_at | INTEGER | 最近一次使用时间 |
| source_session_id | TEXT | 创建来源 Session ID |
| derived_from_agent_id | TEXT | 演化来源 Agent ID（parent） |
| notes | TEXT DEFAULT '' | 使用说明 |
| use_cases | TEXT DEFAULT '' | 适用场景 |
| caveats | TEXT DEFAULT '' | 注意事项 |

### 约束
- `derived_from_agent_id` → FK agents.id（可选，自引用）
- `source_session_id` → FK sessions.id（可选）
- `created_at` / `updated_at` / `last_used_at` 统一使用 Unix timestamp seconds；前端展示时乘以 1000 转为 JavaScript `Date`。
- V2.1 仍属于 Agent Registry / Evolution，不直接执行 Agent 或调用 LLM。

---

## 后端 API 变更

### 新增
| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/v2/agents/from-session/{session_id}` | 从 Session 创建 Agent |
| GET | `/api/v2/agents/catalog` | Agent 目录（按 usage/最近使用排序） |
| GET | `/api/v2/agents/{id}/tree` | Agent 演化树（parent + children） |

### 修改
- `POST /api/v2/agents/{id}/runs` → 自动递增 usage_count + last_used_at
- `POST /api/v2/agents/{id}/clone` → 自动设置 derived_from_agent_id

## 前端变更

### 1. Session Detail → 从 Session 创建 Agent
- Session Detail 页增加 "创建 Agent" 按钮
- 点击后跳转 Editor 页，预填 session 信息
- 保存时调用 POST /api/v2/agents/from-session/{session_id}

### 2. Agent Detail → 演化树 + Notes
- 显示 parent_agent（如果有）
- 显示 children agents（如果有）
- 显示 notes / use_cases / caveats
- 显示 usage_count / last_used_at
- 显示来源 Session 链接

### 3. Agent Editor → 支持 Notes 字段
- 增加 notes / use_cases / caveats 输入区域

### 4. Agent Catalog 页面
- 排序：最近使用 / 使用次数 / 最近更新
- 复用 AgentCard 组件
